# 角色设定图 · 来源与许可

## 上游

- 仓库：[lmy414/ai-chan-sheets](https://github.com/lmy414/ai-chan-sheets)（AI 娘设定图集）

- 本目录的 `catalog.json` 由 `scripts/import-characters.mjs` 生成，记录了生成时的 commit

## 许可与边界

上游采用 **CC BY-NC-SA 4.0**（署名—非商业性使用—相同方式共享）。实际含义：

- **可以**把它当生成参考（提示词、IPAdapter 参考图、ControlNet 输入）
- **不可以**用于商业用途
- **不可以**再分发图像数据本身（包括镜像、打包、批量预取）

因此本插件的做法是：

1. 仓库里**只放元数据**（`catalog.json`）：id、角色名、副标题、品牌、五个槽位的相对路径。
   一张图都不在仓库里，`npm pack` 也不会带上。
2. 图片由服务端代理在**用户点开/取图时**按需拉取一次，落本机缓存，供该用户本地使用。
3. **不做预取、不做镜像、不做批量下载**。导入脚本只调 GitHub 的 tree/raw 接口读 README 与
   `制作清单.json` 这类文本，不碰图片字节。
4. 面板底部与工具返回里都带上许可与署名，来源要求随图走。

部分条目（12–14 号）上游标注的作者为 `unknown`，这里照实保留，不代为归属。
