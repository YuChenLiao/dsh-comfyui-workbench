# 姿势库的数据来源与版权

本目录下的 `catalog.json` 是**元数据**，不是图片。它只包含 288 组姿势的中文名称、分类、
体系归属，以及 1439 张线稿的**地址**。一张线稿都不在仓库里。

## 谁的数据

| | |
|---|---|
| 姿势线稿与原始（日文）数据 | **ギア**（[@giaaibusi](https://x.com/giaaibusi)），作品为 [AI Pose Gallery](https://ai-pose-gallery.pages.dev/) |
| 中文译名与中文版图库 | **Anhao**（[anhao/ai-pose-gallery-zh](https://github.com/anhao/ai-pose-gallery-zh)），镜像站 <https://ai-pose-gallery.anhao.app> |
| 本目录的聚合产物 | 本插件，由 `scripts/import-poses.mjs` 从上游 `data/pose-zh.json` 生成 |

中文译名、分类体系与四体系划分（全身标准 / 全身性感 / 上半身 / 双人）来自 Anhao 的中文版，
上游 README 的记录是「1439 张素体白模 + 1439 张深度图 / 4 大体系 / 26 个动作分类 / 288 组 /
5 种视角」。本插件只取了**白模那一套**，深度图（Depth）、人像库（1499 位）与二次元服装（440 套）
都没有收录。

## 图片怎么用

**运行时不随包分发图片。** 面板与工具要某张线稿时，经本插件的服务端代理按需读取
`https://ai-pose-gallery.anhao.app/{thumbs,img}/…`，取回后落盘到
`<插件数据目录>/cache/poses/`（本机缓存，不再分发）。

代理有三道闸：路径白名单（只认 `thumbs/` 与 `img/` 下的 `jpg`/`png`）、host 固定为 https
图床、响应大小与字节头校验。改这三处中的任何一处都要先想清楚它挡的是什么。

## 使用限制

上游明确说明这些素材**不得用于商业用途**。本插件的 MIT 许可只覆盖它自己的代码
（导入脚本、索引、代理、面板、工具），**不覆盖**任何一张线稿，也不把上游素材的权利
转成 MIT。

需要商用请自行取得ギア的授权。本插件不发图片，只按地址取图 —— 谁取、怎么用，
责任在取用的一方。

## 怎么更新

```sh
npm run poses:import     # 从上游拉 pose-zh.json，聚合后重写 catalog.json
npm run poses:check      # 只校验现有 catalog，不写盘
```

导入脚本会校验：上游条数、四个体系前缀与中文体系名是否对得上、每条图地址是否落在白名单内、
同一组内名称与分类是否一致。任一条不符就报错退出，而不是静默生成一份半坏的数据。

成人向判定写在脚本里，**不是猜的**：整个「性感系 / 双人缠绵」体系，加上分类为
「挤胸・强调事业线系」「性感・大胆系」的组，共 190 组。剩下的 98 组默认可见，
勾选「含成人向」才放开全部 288 组。
